# Multilayer Perceptron

Проект представляет собой реализацию многослойного перцептрона
с графическим интерфейсом и поддержкой обучения на датасете EMNIST.

Приложение поддерживает:

- обучение нейронной сети;
- K-Fold валидацию;
- визуализацию процесса обучения;
- отображение метрик качества;
- сохранение и загрузку весов;
- две независимые реализации нейросети:
  - матричную;
  - графовую.

## Архитектура проекта

Проект реализован с использованием паттерна MVC.

### Структура каталогов

- `model/` — логика нейронной сети и вычислений;
- `controller/` — взаимодействие между моделью и интерфейсом;
- `view/` — графический интерфейс приложения.

## Возможности приложения

Пользователь может:

- обучать модель на CSV-датасетах;
- тестировать качество распознавания;
- запускать K-Fold валидацию;
- сравнивать различные архитектуры сети;
- сохранять и загружать веса модели;
- наблюдать график изменения функции потерь в реальном времени.
